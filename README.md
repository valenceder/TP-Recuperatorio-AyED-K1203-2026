# TP-Recuperatorio-AyED-K1203-2026

Valentín Tomás Cedermas

Comisión: K1203

El programa consiste en un menú, del cual cada opción tendrá su función. Al ejecutarse, se despliegan las opciones disponibles. El usuario puede elegir una opción y llama a la función de la misma. Una vez que terminó de ejecutar (opción 0), el programa no guarda los datos, por lo tanto en la próxima ejecución del mismo arrancará en cero.
