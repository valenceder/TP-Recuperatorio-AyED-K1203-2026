Comisión: K1203

El programa consiste en un menú, del cual cada opción tendrá su función. Al ejecutarse, se despliegan las opciones disponibles. Una vez que terminó de ejecutar (opción 0), el programa no guarda los datos, entonces en la próxima ejecución del mismo se arranca de cero con el menú.
